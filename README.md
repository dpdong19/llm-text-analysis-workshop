# LLM-Assisted Text Analysis Workshop

**Agentic Workflow Series** · SMU Libraries

A hands-on workshop on building an LLM-assisted text classification workflow. Participants use a coding agent to classify airline passenger reviews into service aspects and sentiments, inspect the outputs, refine the prompt, and compare results with a reference set.

## Contents

- `quarto slides/` — Workshop slides (Quarto revealjs)
- `airline-review-workshop/` — Participant project folder (data, classification rules, compare script)

## Dataset

50 airline passenger reviews sampled from the [Airlines Reviews Dataset](https://www.kaggle.com/datasets/sujalsuthar/airlines-reviews) on Kaggle (compiled by Sujal Suthar from [Skytrax](https://www.airlinequality.com/) reviews).
